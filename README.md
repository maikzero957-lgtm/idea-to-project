# حوّل فكرتك إلى مشروع 🚀

منصة ذكية لتحويل أفكارك إلى خطط عمل احترافية باستخدام الذكاء الاصطناعي

## الميزات الرئيسية ✨

- 🤖 **الذكاء الاصطناعي**: يستخدم Claude AI لتوليد خطط عمل احترافية
- 🌍 **دعم ثنائي اللغة**: واجهة عربي/إنجليزي
- 📱 **تصميم responsive**: يعمل على جميع الأجهزة
- ⚡ **سريع وفعال**: توليد خطط العمل في ثوانٍ

## ما تحصل عليه 📋

عند إدخال فكرتك، تحصل على:
- ✅ اسم براند احترافي
- ✅ خطة عمل مفصلة
- ✅ تحليل الجمهور المستهدف
- ✅ قائمة الخدمات المقترحة
- ✅ استراتيجية تسويقية
- ✅ تقدير التكاليف الأولية

## المتطلبات 🛠️

- Node.js 18+
- npm أو yarn
- مفتاح API من Anthropic Claude

## التثبيت والتشغيل 🚀

\`\`\`bash
# استنساخ المشروع
git clone https://github.com/maikzero957-lgtm/idea-to-project.git
cd idea-to-project

# تثبيت المكتبات
npm install

# إعداد متغيرات البيئة
cp .env.example .env.local
# ثم أضف مفتاح API الخاص بك

# تشغيل المشروع
npm run dev
\`\`\`

ثم افتح http://localhost:3000 في المتصفح

## البنية التقنية 🏗️

### Frontend
- **Next.js 14**: Framework React حديث
- **React 18**: مكتبة UI
- **TypeScript**: Type safety
- **Tailwind CSS**: تصميم حديث
- **Framer Motion**: رسوم متحركة سلسة
- **i18next**: دعم اللغات المتعددة
- **Zustand**: إدارة الحالة

### Backend
- **Next.js API Routes**: واجهات برمجية
- **Claude AI**: معالجة الأفكار وتوليد الخطط

## متغيرات البيئة 🔐

\`\`\`env
NEXT_PUBLIC_API_URL=http://localhost:3000/api
OPENAI_API_KEY=your_claude_api_key_here
\`\`\`
